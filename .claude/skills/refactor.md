# Refactor

코드를 리팩토링합니다: $ARGUMENTS

## Workflow

1. **현재 상태 분석**
   - 대상 코드 읽기
   - 코드 스멜 식별 (중복, 긴 함수, 복잡한 조건문 등)
   - 의존 관계 파악 (이 코드를 사용하는 곳)
   - 기존 테스트 확인

2. **리팩토링 계획**
   - 개선 포인트 목록 작성
   - 변경 범위 결정 (최소 범위)
   - 리팩토링 순서 결정 (안전한 순서대로)

3. **테스트 확인**
   - 기존 테스트가 통과하는지 확인
   - 테스트가 없으면 리팩토링 전에 테스트 먼저 추가
   - CLAUDE.md에 정의된 테스트 명령어 사용 (없으면 `pytest -v`)

4. **점진적 수정**
   - 한 번에 하나의 리팩토링만 수행
   - 각 단계마다 테스트 실행하여 동작 보존 확인
   - 기존 코드 스타일과 컨벤션 유지

5. **최종 검증**
   - 전체 테스트 통과 확인
   - CLAUDE.md에 정의된 린터 실행
   - 변경 전후 동작 동일성 확인

## Output Format
```
## Refactoring Summary

### Before
[기존 코드의 문제점]

### Changes
1. [변경 사항 1]
2. [변경 사항 2]
...

### After
[개선된 점]

### Test Results
[테스트 실행 결과]
```
